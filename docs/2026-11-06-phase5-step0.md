# Phase 5 step 5.0 (offline: IOAudioFamily API sketch) — 2026-11-06

No hardware touched. Sources: SDK `Kernel.framework/Headers/IOKit/audio/*.h`, `/System/Library/Extensions/IOAudioFamily.kext` (600.2, compatible 1.0; AppleHDA links 200.5).

## Facts
- macOS 15.8.2; IOAudioFamily 600.2 loaded; all headers present in the CommandLineTools SDK; the existing Makefile (clang -fapple-kext, Kernel.framework headers) compiles against them.
- Kext Info.plist must add `com.apple.iokit.IOAudioFamily` (use 200.5 like AppleHDA).

## API sketch (each item verified in the headers)
- `IOAudioDevice` subclass: `initHardware(provider)`, `setDeviceName/ShortName/ManufacturerName`, `setDeviceTransportType(kIOAudioDeviceTransportTypeBuiltIn)`, `activateAudioEngine(engine)`.
  Attach as a child of our existing PCI-matched class (`attach(this)`, `start(this)`); the PCI function keeps its own `IOMatchCategory`.
- `IOAudioEngine` subclass: pure virtual `getCurrentSampleFrame()`; override `initHardware`, `performAudioEngineStart/Stop`, `convertInputSamples` (custom channel mapping/gain in 5.3);
  `setSampleRate`, `setNumSampleFramesPerBuffer`, `setInputSampleOffset`, `addAudioStream`, and `takeTimeStamp(incrementLoop, &absTime)` once per buffer wrap (an exact wrap time can be passed).
- `IOAudioStream`: `initWithAudioEngine(engine, kIOAudioStreamDirectionInput, 1, desc)`, `setSampleBuffer(ptr, size)`, `addAvailableFormat(&fmt, &minRate, &maxRate)`, `setFormat(&fmt)`, `setTerminalType(INPUT_MICROPHONE)`.
  Format: 2 ch, LinearPCM, SignedInt, depth/width 32, `kIOAudioStreamAlignmentHighByte`, little endian, mixable.
- Controls: `IOAudioLevelControl::createVolumeControl(...)` with usage `kIOAudioControlUsageInput` = the "Input volume" slider; `IOAudioSelectorControl::createInputSelector(...)` with selection `kIOAudioSelectorControlSelectionValueInternalMicrophone` ('imic') =
  the "Internal Microphone" data-source row seen in the target screenshot; both added with `engine->addDefaultAudioControl()`.
- Polling timer: `IOTimerEventSource` on the engine's work loop (no interrupts).

## Decision
5.1 builds exactly this with a synthetic 1 kHz tone source behind a boot-arg `dmic_audio=1` (no DSP, no register access, no DMA).
