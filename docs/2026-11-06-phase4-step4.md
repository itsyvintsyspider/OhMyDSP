## Result: PASS — the DSP delivers DMIC data into host memory
- Order as Linux: RUN set, then TRIG_START (error=0); 500 iterations polled; TRIG_STOP (error=0); RUN cleared; PCM_FREE (error=0); stream undone; ADSPCS back to 0x00000f0f.
- LPIB moved from the first millisecond: 320 B at t=1, 21 440 B at t=50, 226 496 B at t=500, steadily. STS stayed 0x20 (FIFORDY only), no error flags.
- Rate: the loop uses IOSleep(1), which sleeps ~1.17 ms per iteration here, so 226 496 B over ~590 ms = ~384 B/ms. That matches 48 kHz x 2 ch x 4 B; the "452 B/ms" in the log is the loop-time artefact, not a rate problem. 4.5 should log a real timestamp.
- Data: 56 624 words (28 312 frames) in the DMA-reported region, min -76 215 360, max 81 678 592 (about 3.8 % of full scale), 28 208 non-zero, no guard-pattern words left. The first 8 words are 0 (pipeline start-up), then non-zero.
