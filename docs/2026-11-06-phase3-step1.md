## Learned
- Firmware accepted a pipeline whose scheduler component (DAI id 56) does not exist yet, as in Linux's order (ABI 3:22 tolerates it).
- Reply `hdr.cmd` echoes the request command; reply size is 20 (> the 12-byte `sof_ipc_reply`), so the reply parser must use `hdr.size`, not a fixed size.
- Message-content values (inferred from source + topology) were accepted without error; they are still unverified against a Linux trace, only "not rejected".
