# Phase 5.3 - live microphones in CoreAudio

Date: 2026-11-06. Result: **PASS** (with one open item: mic A is still silent, so the "joined" signal is mic B alone).

## What was tested (boot-arg dmic_audio=2, kext loaded manually with tools/load-kext.sh)
The engine's sample buffer is the DSP's 128 KiB DMA ring. Engine start = checkIdle, powerUp, sendPipeline(19), startStream(mode 4, SD5);
engine stop = stopDma, freeStream, teardown. A 5 ms timer polls LPIB and stamps every ring wrap. The input join averages both channels
when both carry signal, otherwise uses the live channel alone, then applies software gain and sends the result to both output channels.

## Results
- System Settings > Sound > Input lists the OhMyDSP "Internal Microphone" (Built-in); the level meter moves and the input volume slider works.
- `recordtest` 5 s: 469 IOProc calls, 240128 frames (expected 240000), no overloads.
- Voice Memos recorded 11 s from the device (rms about -22 dBFS, peaks -3..-7 dBFS, no clipping).
- Engine start latency: 112-114 ms power-up + firmware, 23-24 ms pipeline, 2 ms stream, total 139-148 ms over 13 starts. No app timeout.
- Cycle test: 11 real engine starts, all OK; 11 stops, all "DMA stop OK, stream free clean, DSP down" (about 2 ms); no stuck RUN, no SD error flags.
- Ring wraps 3/s as expected (0.34 s ring); LPIB sweeps smoothly; no stall lines over 10+ minutes of running (about 38M frames).
- Coexistence: a 10 s recording while sound played through the built-in output ran clean; Apple Built-in Output/Line Input/Microphone stayed present;
  no new "Sound assertion" lines. (Whether the music glitched: reported by the user, not measurable from the log.)

## Findings
- Default gain +17 dB clipped claps (2.3% of frames). Slider mapping is now (v-60)/2 dB (default 75 -> +7 dB, 100 -> +20 dB). Verified live with
  `engine-tune gain_db=7` (2 clipped samples in 5 s, rms -22..-27 dBFS); the new default needs a rebuild (not yet built, no new approval needed until then).
- If System Settings > Sound is open, its meter holds the input and the engine never stops, so loops of recordtest do not cycle the DSP. Close it for start/stop tests.
- One boot after a kext-approval restart came up with no Apple output devices ("Sound assertion in IOHDACodecDevice" at boot, before our kext loaded;
  AppleHDAController had no codec). A full power-off fixed it. Not caused by this kext; expect it after warm restarts on this machine.
- Mic A (left) is still digitally silent; the DAI_CONFIG clk_edge/skew experiment is parked.
